<h3 style="text-decoration: underline;">Reverse Engineering and Software Analysis</h3>

[iBase](https://github.com/jzhang369/daniARM32RE) automatically infers the image base address of an ARM32 binary by statistically, structurally, and semantically correlating the absolute and the relative addresses contained in the binary. It has two unique features: i) iBase exploits ARM32’s architecture features, and hence it is immune to variances introduced by software development and compilation; ii) iBase is parameter-free and it requires no manual configuration.
